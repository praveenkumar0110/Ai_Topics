🧠 Big Picture – indha program enna pannudhu?

Neenga run pannina:

python screenshot_mcp.py


Indha oru file la:

Client run aagum

Client marubadiyum same file ah server mode la run pannum

Client → URL anupum

Server → Browser open pannum → Screenshot edukkum

Server → Path thirupi anupum

Loop la multiple screenshots edukkalam

🔹 Imports
import asyncio
import sys
import os
from datetime import datetime


asyncio → async client/server communication

sys → server mode check panna

os → folder create panna

datetime → unique file name create panna

from mcp.server import FastMCP
from mcp import ClientSession
from mcp.client.stdio import stdio_client, StdioServerParameters
from playwright.async_api import async_playwright


FastMCP → MCP server create panna

ClientSession → MCP client create panna

stdio_client → same file la client/server talk panna

async_playwright → browser automation

🔹 MCP Server create pannuring

Meaning:

“ScreenshotTool nu oru MCP server create panren”

Idhu AI / client call panna mudiyura tool.

Folder create
os.makedirs("screenshots", exist_ok=True)


screenshots/ folder illa na create pannum.

Unique file name
timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
screenshot_path = f"screenshots/screenshot_{timestamp}.png"


Every run → new file.

Old image overwrite aagathu.

Browser open pannudhu
async with async_playwright() as p:
    browser = await p.chromium.launch(headless=True)


Chromium browser open pannudhu

headless=True → UI illa background la run

Page open pannudhu
page = await browser.new_page()
await page.goto(url, timeout=60000)


URL ku pogudhu.

Screenshot edukkudhu
await page.screenshot(path=screenshot_path, full_page=True)


Full page screenshot.

Browser close
await browser.close()

Path return pannudhu
return f"Screenshot saved at: {screenshot_path}"


Server idha client ku anupum.
